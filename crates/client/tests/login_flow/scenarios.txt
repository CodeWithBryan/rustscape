#   env WINDOW WIDTH HEIGHT AA UID SETTINGS AFFILIATE PREFS VERIFY CRCBASE ADVERT

#   state N / setstate N              store / client.setGameState
#   login USER PASS TYPE, continue, resetlogin            commands 5600-5602
#   checkinfo D M Y C, checkname NAME, create D M Y C NAME PASS AFFILIATE,
#   resetcreate, names                                    commands 5603-5606, 5610
#   fetch NOW, hop ID, sort A B C D, list, get ID         WorldList
#   connect ok|fail, recv TOKENS, recvlen TOKENS, eof, ioerr     the server side
#   lost TIMER                        Protocol.handleConnectionLost
#   tick N                            N client cycles
